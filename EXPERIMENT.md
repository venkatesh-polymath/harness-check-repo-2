## Idea
SSL Spurious-Correlation Suppress-vs-Shift Audit on Togglable-Signal CIFAR Suite

## Prediction (registered before running)
SimCLR/BYOL pretraining will suppress the spurious signal it is exposed to during pretraining (e.g., background color) but increase exploitation of a simultaneously present held-out signal (e.g., injected color patch), confirming a shift rather than a suppress. ERM WGA = 59.9% [arxiv-2302.12254]; SSL WGA on trained signal will improve by 5–8%, but WGA on held-out signal will drop 3–5% vs ERM.

## Hypothesis chain (sanity gates FIRST)
  1. Setting a single global seed (torch, numpy, random, CUDA) before all initialization produces bit-identical initial weights and data-loading order across two independent process launches. → expect: Per-step cross-entropy loss for the first 10 optimizer steps matches exactly between the two seeded runs. (pass if max(|loss_run1[t] - loss_run2[t]|) < 1e-6 for t in 0..9)
  2. A randomly-initialized 10-class classifier produces a cross-entropy loss near ln(10) ≈ 2.303 at step 0, before any gradient update. → expect: Logged loss_0 falls in [2.1, 2.5] across all model variants (ResNet-8, small ViT). (pass if |loss_0 - 2.303| < 0.2)
  3. A model that ignores all pixel inputs and always predicts a uniform distribution achieves exactly chance accuracy on a class-balanced test set. → expect: Dummy classifier accuracy = 10.0 ± 0.5% on balanced CIFAR-10 test split (1000 samples/class). (pass if dummy_acc ∈ [9.5%, 10.5%])
  4. The architecture can memorize a single fixed batch of 32 samples, reaching near-zero training loss via gradient descent alone. → expect: After 200 SGD steps on a frozen batch (lr=0.01), training cross-entropy < 0.01. (pass if train_loss_step200 < 0.01)
  5. The togglable-signal dataset pipeline correctly injects the background-color spurious feature at controllable correlation strength: a shallow linear probe trained only on per-image HSV color histograms (no class-label signal) should decode class at ≥85% accuracy when correlation=1.0 and fall to near chance when correlation=0.0. → expect: LinearProbe(HSV histogram → class) achieves ≥85% train accuracy at ρ=1.0 and ≤15% at ρ=0.0. (pass if lp_background_acc(ρ=1.0) ≥ 0.85 AND lp_background_acc(ρ=0.0) ≤ 0.15)
  6. The injected held-out spurious signal (a small solid-color patch in a fixed corner, correlated with class but absent from SSL augmentation crops) is also independently decodable by a linear probe on patch-region color statistics. → expect: LinearProbe(patch color → class) achieves ≥85% train accuracy at ρ=1.0 and ≤15% at ρ=0.0, independently of background. (pass if lp_patch_acc(ρ=1.0) ≥ 0.85 AND lp_patch_acc(ρ=0.0) ≤ 0.15)
  7. ERM trained on data where both spurious signals are simultaneously active exploits at least one, yielding high average accuracy but low worst-group accuracy (WGA) on the group that has the spurious signal flipped. → expect: ERM avg_acc ≥ 85%, WGA on background-flip group ≤ 65%, WGA on patch-flip group ≤ 65%. (pass if erm_avg_acc ≥ 0.85 AND (erm_wga_background ≤ 0.65 OR erm_wga_patch ≤ 0.65))
  8. SimCLR pretraining with color-jitter and grayscale augmentations (which cover background-color variation) suppresses the background-color spurious feature in the learned representation: a linear probe on frozen SimCLR features decodes background class-color substantially worse than a probe on ERM features. → expect: lp_simclr_background_acc < lp_erm_background_acc − 10pp. (pass if lp_erm_background_acc - lp_simclr_background_acc > 0.10)
  9. SSL pretraining improves worst-group accuracy on the background-color spurious split relative to ERM by 5–8pp, confirming partial suppression of the trained spurious signal. → expect: wga_ssl_background − wga_erm_background ∈ [+5pp, +8pp]. (pass if wga_ssl_background - wga_erm_background ≥ 0.05)
  10. Because the color-patch held-out signal is not covered by SimCLR's augmentations (patch is preserved in standard random-crop views), SSL does not suppress it; instead, reducing competition from the background signal causes the model to lean more heavily on the patch signal, lowering WGA on the patch-flip group relative to ERM. → expect: wga_erm_patch − wga_ssl_patch ∈ [+3pp, +7pp] (SSL is worse on the held-out signal). (pass if wga_erm_patch - wga_ssl_patch ≥ 0.03)
  11. The magnitude of improvement on the trained-signal WGA and the magnitude of degradation on the held-out-signal WGA are of similar scale, consistent with a correlation-shift rather than net suppression. → expect: |ΔWGA_background - |ΔWGA_patch|| < 3pp; both deltas are non-trivial (>3pp each). (pass if abs((wga_ssl_background - wga_erm_background) - (wga_erm_patch - wga_ssl_patch)) < 0.03 AND (wga_ssl_background - wga_erm_background) > 0.03 AND (wga_erm_patch - wga_ssl_patch) > 0.03)
  12. Extending SimCLR's augmentation policy to explicitly cover the patch region (patch-erasing or patch-color-jitter augmentation) simultaneously suppresses both spurious signals, eliminating the shift and improving WGA on both splits vs. ERM. → expect: wga_ssl_full_background > wga_erm_background AND wga_ssl_full_patch > wga_erm_patch, both by ≥4pp. (pass if (wga_ssl_full_background - wga_erm_background) ≥ 0.04 AND (wga_ssl_full_patch - wga_erm_patch) ≥ 0.04)
  13. The suppress-vs-shift effect is amplified in the 50-labels/class low-label regime relative to the 500-labels/class regime: the WGA degradation on the held-out signal is at least 2pp larger when fine-tuning with only 50 labels/class, because fewer labels cannot correct the shifted inductive bias. → expect: (wga_erm_patch_50 − wga_ssl_patch_50) > (wga_erm_patch_500 − wga_ssl_patch_500) + 2pp. (pass if (wga_erm_patch_50 - wga_ssl_patch_50) - (wga_erm_patch_500 - wga_ssl_patch_500) > 0.02)

## Study spec
- goal: Determine whether SSL pre-training suppresses spurious-feature reliance (lower accuracy gap between spurious-signal-ON and spurious-signal-OFF test splits) versus merely shifting it to a different shortcut, relative to supervised ERM, across togglable-signal CIFAR-10 variants.
- scientific (measure): ['ssl_method: {supervised_erm [baseline], simclr, byol, moco_v2, barlow_twins}', 'spurious_signal_type: {foreground_color_patch, background_texture, corner_watermark}', 'train_spurious_rate: {0.0, 0.5, 0.75, 0.90, 1.0} — fraction of training examples where spurious cue is class-correlated', 'test_signal_toggled: {present, absent} — whether spurious cue is rendered at evaluation time']
- nuisance (tune per arm): ['lr_pretrain: grid-searched per ssl_method (contrastive methods need larger LR than supervised)', 'lr_linear_probe: grid-searched per ssl_method × train_spurious_rate arm', 'temperature: tuned per contrastive method (N/A for byol/barlow_twins/supervised)', 'batch_size: tuned per ssl_method (SimCLR degrades at small batch; supervised does not)', 'augmentation_strength: tuned per ssl_method (strong crop+color-jitter canonical for contrastive; lighter for supervised to avoid destroying spurious cue artificially)', 'projection_head_dim: tuned per ssl_method']
- fixed (hold constant): ['architecture: ResNet-18 [caveat: known to memorize CIFAR well; larger arch may shift memorization capacity]', 'dataset_base: CIFAR-10 (50 k train / 10 k test, 10 balanced classes)', 'image_size: 32×32', 'pretrain_epochs: 200 (linear-probe: 100)', 'optimizer: SGD momentum=0.9, weight_decay=1e-4', 'global_seeds: {0, 1, 2} — three independent runs per arm; seed scope: torch + numpy + random + CUDA (sanity-check: step-0 CE loss must be within 0.01 of ln(10)=2.303 and bit-identical across seed-matched relaunches)', 'null_model_gate: constant-uniform predictor must achieve exactly 10 % accuracy on balanced test split before any arm runs', 'memorization_gate: architecture must reach loss < 0.01 on a fixed batch of 32 samples within 200 SGD steps before any arm runs', 'linear_probe_protocol: freeze backbone, train single linear layer only — same for all arms', 'spurious_signal_renderer: deterministic pixel-space overlay keyed on (class, split, seed) — toggle is a binary flag, not a separate dataset']
- baseline: Supervised ERM on CIFAR-10 with train_spurious_rate=1.0 and test_signal_toggled={present, absent}: this is the canonical, well-documented shortcut-learning reference (cf. Geirhos et al. 2020, Shah et al. 2020) that defines the susceptibility ceiling — maximum accuracy gap — against which all SSL methods are benchmarked.
- eval contract: Dataset: Togglable-signal CIFAR-10 suite (same 50 k / 10 k split, two test forks: signal-ON and signal-OFF). Primary metric: spurious-reliance gap = Acc(signal-ON) − Acc(signal-OFF); secondary metric: worst-group accuracy (WGA) across the four subgroups (signal-present/absent × correct-class/spurious-class). CV scheme: 3 fixed seeds per arm, bootstrap 95 % CI (n=10 000 resamples) over seed × test-example pairs. Significance test: paired permutation test (10 000 shuffles) comparing each SSL method's gap against the supervised-ERM baseline gap within each spurious_signal_type × train_spurious_rate cell; Holm-Bonferroni correction across the 3 × 5 = 15 cells per method.
