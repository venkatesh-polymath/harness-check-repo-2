## Idea
Observable Temporal Precedence Map: Which Cheap Signal Leads Plasticity Collapse — and by How Many Tasks?

## Prediction (registered before running)
Gradient-noise scale (McCandlish B_opt estimator, two mini-batches per step) will show the longest lead time (5–15 tasks before accuracy collapse) under SGD+momentum. Effective rank of penultimate-layer activations will be second (3–10 tasks). Dead-unit fraction will be third (1–5 tasks). Weight-norm drift will be near-contemporaneous with collapse (0–2 tasks). Under Adam, per-coordinate gradient normalization will suppress variance and collapse the noise-scale signal — making effective rank the dominant leading indicator. This optimizer-conditional reversal would explain why the existing rank/dead-unit-focused literature, which almost universally uses Adam, has not identified gradient-noise scale as predictive.

## Hypothesis chain (sanity gates FIRST)
  1. With a fixed random seed the entire training setup is deterministic: same initialization, same data ordering, same loss trajectory across two independent runs. → expect: Two runs launched with identical seed produce bit-identical per-step loss values and identical parameter checksums at run end. (pass if max(|loss_run1[t] - loss_run2[t]|) < 1e-6 for all logged steps; L2 distance between final parameter vectors = 0.0.)
  2. At random initialization, before any gradient update, cross-entropy loss on C classes equals log(C) (uniform-prediction prior), confirming no initialization leakage or accidental label memorization. → expect: Mean cross-entropy at step 0 is within ±0.05 of log(C) for CIFAR-10 (≈2.303) and CIFAR-100 (≈4.605) on a 1000-sample probe batch. (pass if abs(initial_loss - log(num_classes)) < 0.05 on the probe batch before any weight update.)
  3. A model trained on randomly permuted labels (input-independent baseline) cannot exceed chance accuracy, confirming that any accuracy gain in real training reflects genuine signal extraction rather than dataset artifacts. → expect: After full training on shuffled labels, test accuracy on shuffled-label data is within ±1 pp of 1/C (10% for CIFAR-10, 1% for CIFAR-100). (pass if Shuffled-label test accuracy in [1/C − 0.01, 1/C + 0.01] after 50 training epochs.)
  4. The optimizer and network can drive a single fixed batch to near-zero training loss when optimized repeatedly, confirming that gradient flow and architecture capacity are functional. → expect: Cross-entropy loss on a single fixed batch of 64 CIFAR-10 examples falls below 0.01 within 200 gradient steps using SGD+momentum (lr=0.01, m=0.9) on a 3-hidden-layer MLP (width 256, ReLU). (pass if loss_fixed_batch[step=200] < 0.01.)
  5. ## Study spec
- goal: Quantify the lead time in tasks by which each of four cheap signals (dead-unit fraction, activation effective rank, gradient-noise scale, weight-norm drift) precedes plasticity collapse on Split-CIFAR-10, and test whether that temporal-precedence ordering is consistent or config-conditional across a 2×2 optimizer × BatchNorm factorial.
- scientific (measure): ['optimizer ∈ {Adam, SGD} — tests the falsifiable sub-hypothesis that Adam suppresses the gradient-noise-scale lead signal relative to SGD, potentially inverting its rank in the precedence ordering', 'batchnorm ∈ {on, off} — tests whether BN confounds dead-unit fraction and effective rank enough to alter the precedence ordering; all four observables measured on pre-BN (pre-normalization) activations in both arms so the measurement node is identical across the BN factor']
- nuisance (tune per arm): ['learning_rate: tuned independently per optimizer arm to match early-task (tasks 1–3) loss-AUC within ±5% of the baseline arm; Adam grid [1e-4, 3e-4, 1e-3], SGD grid [1e-2, 3e-2, 1e-1]; selected value held fixed across all tasks in that arm', "weight_decay: tuned per optimizer arm to match the baseline arm's early-task weight-norm trajectory (Adam: [0, 1e-4, 1e-3]; SGD: [0, 1e-3, 5e-3]); ensures weight-norm drift observable is not artificially inflated or suppressed by regularization asymmetry", 'gradient_noise_scale estimator mini-batches: tuned per BN arm to achieve <5% relative SE on the GNS estimator (BN alters per-sample gradient variance); target sample size confirmed on task 1 before main runs']
- fixed (hold constant): ['architecture: 3-layer MLP (400–400 hidden units, ReLU) matching Dohare et al. CBP paper exactly — caveat: precedence ordering may not transfer to convolutional or attention-based architectures', 'dataset and task sequence: Split-CIFAR-10, 10 tasks × 2 disjoint classes, class permutation fixed at seed=0 across all arms', 'steps per task: 2 000 gradient steps, matching CBP paper protocol', 'random seeds: 5 seeds {0,1,2,3,4} — caveat: thin for strong consistency claims; first pass is explicitly exploratory; Kendall W reported with 95% bootstrap CIs', 'collapse event (t_collapse): first task t at which new-task test accuracy is ≥20 pp below task-1 accuracy AND remains below for ≥2 consecutive tasks; uses trainability (new-task) accuracy per reviewer requirement; fixed before any run', "onset criterion: PELT changepoint on each z-scored per-signal trajectory, z-scored against the tasks 1–5 baseline window; onset = first task the signal deviates ≥k robust-SDs from baseline and stays deviated; primary k=2.0, mandatory sensitivity sweep k∈{1.5, 2.5} — any precedence-rank flip across k values flagged as threshold-sensitive and excluded from the 'consistent ordering' claim", 'lead-time metric: lead_time(signal) = t_collapse − onset(signal) in integer tasks; positive = signal fires before collapse; framing is predictive temporal precedence, NOT causal', 'sanity-check protocol (all four must pass before main runs proceed): (1) two independent fixed-seed runs produce bit-identical loss trajectories; (2) CE loss at random init = log(10) ± 0.01; (3) permuted-label arm accuracy ≤ 12% throughout all 10 tasks; (4) 500 steps on one fixed batch drives loss to <0.01', 'compute budget: ~60 A10G-hours total per original estimate; per-run wall-clock logged and reported']
- baseline: Vanilla continual learning: 3-layer MLP (400–400, ReLU), SGD with nuisance-tuned LR and weight decay, BatchNorm OFF, Split-CIFAR-10, 10 tasks, 5 seeds, zero plasticity repair. Replicates the collapse trajectory documented in Dohare et al.; establishes the reference t_collapse distribution and all four signal trajectories before any optimizer or BN factor is introduced. Built and verified first.
- eval contract: Dataset: Split-CIFAR-10 (10 tasks × 2 classes, fixed permutation seed=0). Primary metric: lead_time(signal) = t_collapse − onset(signal) in tasks, per signal × optimizer × BN arm, reported as mean ± 95% bootstrap CI over 5 seeds. Precedence-ordering consistency: Kendall's W (coefficient of concordance) over the 5 per-seed signal orderings within each optimizer × BN cell; W ≥ 0.70 → 'consistent ordering' (pre-registered threshold); W < 0.70 → 'config-conditional or noisy.' Pairwise lead-time differences between the 4 signals tested with Wilcoxon signed-rank (paired over seeds, Bonferroni-corrected for 6 pairs, α=0.05). Sensitivity: full ordering re-derived at k∈{1.5, 2.5} alongside k=2.0; any rank flip reported as a finding, not suppressed.
